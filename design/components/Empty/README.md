An empty state is an opaque sheet with a dashed outline (`sheet` plus a dashed border, the draughtsman's mark for "nothing here yet") with the Forge mark at 40px and one `body` sentence in `muted`, centred with `space-10` vertical padding. The sentence names the command that fills it, in `mono`.

Use it wherever a list has nothing yet: no jobs match, no backlog, no log lines, no evals. No button, no illustration beyond the mark.

Static rendition in the Drafting direction; replaces `Empty.svelte`.
