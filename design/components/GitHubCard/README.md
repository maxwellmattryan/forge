A GitHub hover card is a solid sheet with ticks (`.sheet.ticks.solid`) and `shadow-dialog`, 360px wide (the viewport less 16px gutters on phones), fixed 6px below the link it describes, or above it when there is more room there. It holds a `label` line naming the kind and repository with a state chip at its end, the title as a `card` heading, a muted excerpt clamped to three lines, chips for checks, review and labels, a `caption` facts line, and a footer under a `line` rule: the page's path in `mono` and an *Open on GitHub* `btn sm`.

Use it for links to a github.com repository, pull request, issue or commit, anywhere in the dashboard. It opens after a resting mouse pointer (400ms) or on keyboard focus, never on touch, and closes when the pointer leaves the link and the card (250ms grace), on Escape, or when focus moves on. Chip tones follow the board's PR chip: merged and approved `ok`, open `info`, closed and draft `muted`, failing checks and requested changes `bad`, pending `warn`.

It is a `role="tooltip"` the link names with `aria-describedby`: the link stays the keyboard's way to GitHub, and the card's own links are for the pointer (`tabindex="-1"`). Everything in it is GitHub text and renders as text.
