A progress bar is an 8px outlined track (`1px line`) with an `ink` fill cross-hatched at `hatch-dense` (4px), a 1px `ink` tick overshooting the fill's end by 4px like a dimension end, and `done/total` in `label`-size mono `muted` numerals.

Use it for a job's `tasks.md` progress on cards and in the drawer; budget rows use the same track with a solid `ok`, `warn` or `bad` fill. Never animate the fill or label the track.
