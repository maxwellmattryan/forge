A segmented control is a `.seg` strip of `.btn`s sharing their 1px borders, the selected one solid `ink` (`.sel`). Use it for a small set of exclusive choices: the board/table layout toggle (with icons), the pipeline filters (with counts in `muted`), the theme and density choices in settings. Two to five segments; the selected segment is the only filled thing in the row.

Static rendition in the Drafting direction; replaces the layout toggle and filter row in `views/Pipeline.svelte`.
