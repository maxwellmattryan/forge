The sidebar is a `size-sidebar` (236px) column of opaque `chrome`, the furthest step from the ground, with a `line-strong` right edge and a hard 8px `shadow-chrome` over the main column (the sidebar sits at z-10; the drawer and dialogs still cover it), so the grid and paper stop at its edge. It holds the brand sheet (the mark, *Forge* in `sheet-title`, *software factory* in `label`), a dimension line naming the drawing (`DWG · PIPELINE`), the repo in `mono`, the view nav, and at the foot the Settings item and a title block (DRAWN BY / SESSIONS / REV / API / SHEET) in place of a footer.

The SESSIONS cell is a heartbeat for the daemon: the `LiveDot` (on, with its halo, while any daemon session, the inbox or a job's, is working or waiting on a permission; a hollow dot otherwise) and *N active*. Its tooltip lists the active sessions one per line (*inbox*, then job ids) or reads *No session is working*. The Agents view still lists orchestrator sessions.
Use it as the one navigation surface at md and up; below md the items become a horizontal strip and the settings button a 44px target, and the strip carries the same live dot and *N active* (with the same tooltip) between the nav and the settings button. It holds navigation only: the command palette opens from the status bar and the drawer (see CommandBar and StatusBar). The title block is the only place the version appears.
