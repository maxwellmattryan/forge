The sidebar is a `size-sidebar` (236px) column of opaque `chrome`, the furthest step from the ground, with a `line-strong` right edge and a hard 8px `shadow-chrome` over the main column (the sidebar sits at z-10; the drawer and dialogs still cover it), so the grid and paper stop at its edge. It holds the brand sheet (the mark, *Forge* in `sheet-title`, *software factory* in `label`), a dimension line naming the drawing (`DWG · PIPELINE`), the repo in `mono`, the view nav, and at the foot the Settings item and a title block (DRAWN BY / SESSIONS / REV / API / SHEET) in place of a footer.

Use it as the one navigation surface at md and up; below md the items become a horizontal strip and the settings button a 44px target. It holds navigation only: the command palette opens from the page header, the phone FAB and the drawer (see CommandBar). The title block is the only place the version and session count appear.

Static rendition in the Drafting direction; replaces the `aside#sidebar` in `App.svelte`.
