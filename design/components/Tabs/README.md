Tabs are `nav`-style labels on a `line` baseline; the active tab draws its own three sides in `line` and fills with `bg`, so it reads as a folder tab cut into the rule. Inactive tabs are `muted` and hatch on hover.

Use tabs to switch facets of one object (the drawer's Files, Timeline, Thread); counts beside a label are `muted`. Many sections get the settings rail instead.

Static rendition in the Drafting direction; replaces the drawer's tab strip.
