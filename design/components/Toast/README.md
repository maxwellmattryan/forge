A toast is a small solid sheet (`.solid`: `bg` fill so it covers what is beneath) fixed bottom-centre, `body` text, `space-4`/`space-2` inset, with `shadow-dialog`. An error toast sets its text in `bad` and leads with a `rev` chip.

Use a toast to confirm a request the person just made or to report that it failed; one at a time, self-dismissing, with a permanent live region so screen readers hear each message. One line, no action.
