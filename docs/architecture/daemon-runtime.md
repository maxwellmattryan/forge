# Daemon runtime

How each daemon session runs: session files and offsets, resume, failures, start and stop, effort, the HTTP surface, the terminal, orphans, role runs and their context sessions, and the recorded stream-json framing. [Daemon](daemon.md) covers when sessions run, and [Daemon security](daemon-security.md) what they may do.

- [Sessions](daemon-runtime/sessions.md): [Files](daemon-runtime/sessions.md#files), [Offsets](daemon-runtime/sessions.md#offsets), [Session and resume](daemon-runtime/sessions.md#session-and-resume), [Rotation](daemon-runtime/sessions.md#rotation), [Failures](daemon-runtime/sessions.md#failures), [Start and stop](daemon-runtime/sessions.md#start-and-stop), [Effort](daemon-runtime/sessions.md#effort), [Stopping and orphans](daemon-runtime/sessions.md#stopping-and-orphans), [Recorded framing](daemon-runtime/sessions.md#recorded-framing). Read it before changing how a session is spawned, logged, resumed or stopped.
- [The HTTP surface and terminal](daemon-runtime/surface.md): [HTTP surface](daemon-runtime/surface.md#http-surface), [Terminal](daemon-runtime/surface.md#terminal). Read it before changing a daemon route, the `daemons` state or `forge daemon status` and `log`.
- [Role runs](daemon-runtime/role-runs.md): [Role runs](daemon-runtime/role-runs.md#role-runs), [Resume](daemon-runtime/role-runs.md#resume), [Lean sessions](daemon-runtime/role-runs.md#lean-sessions), [Context sessions](daemon-runtime/role-runs.md#context-sessions). Read it before changing how a role runs as its own child: its argv, env and files, rework resumes or context sessions.
- [The code driver](daemon-runtime/code-driver.md): [Code driver](daemon-runtime/code-driver.md#code-driver). Read it before changing how `forge dash` drives a job's turns itself under `daemon.driver: code`.
