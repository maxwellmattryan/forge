# Daemon security

The daemon runs an unattended agent under `daemon.allowedTools`, asking a human in the dashboard about anything else (or, with `--permission-mode dontAsk`, refusing it, or, in a session a human switched to `auto`, letting Claude Code's classifier decide), so its inputs are narrow on purpose. These parts hold each rule, under its bold name.

## Parts
- [Session inputs](daemon-security/session-inputs.md): what reaches a session's stdin, environment and argv, and why config is code. Holds **One fixed stdin turn**, **The scope travels in the environment only, validated**, **argv comes from the repo's config, with no shell**, **Trust boundary: `.forge/config.yml` is code**, **Configured commands get an allowlisted environment and no login shell, in every mode**.
- [Write confinement](daemon-security/write-confinement.md): the protected set, write roots and the five layers (trust digest, confine digest, scoped file tools, deny tail, write guard), and the CLI copy of job state. Holds **The session can't change what Forge executes, what every agent reads, or anything outside its write roots**, **protected set**, **write roots**, **confine digest**, **The CLI owns job state (#448)**, **CLI copy**, **Residual risk**, **Keeping a slot and marking agents lost read `job.json`, which the session writes through `forge`**, **`--body-file` publishes only the session job's own files**.
- [Human-only operations](daemon-security/human-only-operations.md): the terminal and dashboard channels a session's children can't reach, and the dashboard routes that start, stream and read sessions. Holds **Human-only operations**, **Start and stop**, **SSE is loopback-only and per session**, **History reads are confined**.
- [Permissions](daemon-security/permissions.md): permission prompts, the permission mode, effort, the narrow tool list and git hooks. Holds **Permission prompts are answered from the dashboard only**, **Permission mode is a human's choice, held in memory**, **Auto on one session reaches the whole daemon**, **Effort is a human's per-job setting, read back from `job.json`**, **Narrow permissions, still not a sandbox**, **Git hooks are off in the session and in the periodic sync**.
- [Runners](daemon-security/runners.md): the intake runner, role runs (worktree deny rules, setting sources, tools, the browser, the trusted prefix, context sessions) and the code driver. Holds **The intake runner answers inbox requests with fixed CLI calls, and its triage child writes one batch dir**, **Role runs are confined as a job session's subagents are, without a person to ask**, **context session**, **The code driver adds no input a session didn't have**.
- [Spend](daemon-security/spend.md): per-key budgets, the dollar cap per spawn, provider switches and the supervisor's meter. Holds **Spend caps under the daemon**, **Metered spend**.
- [Chats](daemon-security/chats.md): the owner's chat sessions and their five attackers. Holds **Chats**.
- [Machine dashboard](daemon-security/machine-dashboard.md): orphan reaping, starting and widening the machine dashboard, pool approval, the inherited environment, the login service, the proven dashboard record and the logs. Holds **Orphan reaping**, **The machine dashboard is a human's to start, stop and widen**, **A project's pool boots with the machine dashboard only while a human's approval still matches its files**, **Every project's sessions and commands inherit the environment of the shell that started the machine dashboard**, **The login service is a human's to install, and carries no credentials**, **The dashboard record is proven, not trusted**, **The logs**.
