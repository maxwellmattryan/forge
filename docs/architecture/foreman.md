# Foreman

Unattended runs stop at every human gate. With `foreman.enabled` (off by default; docs/CONFIG.md "Foreman"), `forge dash`'s gate runner decides the gates the Foreman is allowed to, in code, with one fresh `forge:assistant` process per gate, so a human is needed only where policy says so.

Read it before changing which parks reach the Foreman or how a gate run decides one.
- [Authority, audit and threat model](foreman/authority.md): [Authority](foreman/authority.md#authority), [Audit](foreman/authority.md#audit), [Threat model](foreman/authority.md#threat-model), [Gate run threat model](foreman/authority.md#gate-run-threat-model). Read it before changing who may record a foreman decision or what the Foreman may decide.
- [Releases](foreman/releases.md): [The release gate class](foreman/releases.md#the-release-gate-class), [Release gate threat model](foreman/releases.md#release-gate-threat-model), [A mandate's release](foreman/releases.md#a-mandates-release), [Mandate release threat model](foreman/releases.md#mandate-release-threat-model).
