## Behaviours

### yaml.ts: parse
- B1. A GitHub project-config document (comment header, nested maps, `number: 8`, a sequence of double-quoted emoji strings, `defaults.status: "📚 Backlog"`) parses to `doc.project.number === 8`, `doc.fields.status.options` = `['📚 Backlog','🏗 In Progress','🎉 Done']`, `doc.defaults.status === '📚 Backlog'`. Old: test/yaml.test.ts › "parses a GitHub project-config file"
- B2. Sequences of maps (`- name: code\n    always: true`), a flow map item (`- { name: ui, when: "visual changes" }`), a flow list with mixed quoting (`[a, 'b c', 3]` → `['a','b c',3]`), a `#` inside a value without preceding space kept (`https://example.com/x#frag   # trailing comment` → `https://example.com/x#frag`), a `|` block (`line one\nline two\n`), and an empty value (`empty:` → null). Old: test/yaml.test.ts › "handles sequences of maps, flow collections, block scalars and comments"
- B3. Scalars: `~`, `null`, `Null`, `NULL` → null; `true|True|TRUE` / `false|False|FALSE` → booleans; `yes` stays the string `yes`; integers and decimals (`+3` → 3, `.5` → 0.5, `1e3` → 1000); `0x1` stays a string; `'it''s'` → `it's`; `"x\ty"` → JSON escapes. An empty document or one with only comments → null; `---` and `...` lines are ignored. Old: none (from source; verified against the implementation)
- B4. Block scalars: `|` keeps newlines plus a final one; `|-` drops the final newline (`a: |-\n  x\n` → `'x'`); `>` folds single newlines to spaces and keeps blank lines (`one\ntwo\n\nthree` → `'one two\n\nthree\n'`). Old: test/yaml.test.ts › "handles sequences of maps, flow collections, block scalars and comments" (`|`); the rest from source
- B5. A same-indent sequence under a key (`a:\n- 1\n- 2`) → `{a:[1,2]}`; nested sequences (`-\n  - x`) → `[['x']]`; flow collections nest (`[1, [2, 3], {b: c}]`) and allow a trailing comma (`[1,]` → `[1]`, `{b: 1,}` → `{b:1}`); quoted keys unquote (`"q k": 1`). Old: none (from source)

### yaml.ts: stringify
- B6. `parse(stringify(v))` deep-equals `v` for a config-like value with nested maps, a list of maps, `null` values, emoji strings, `multiline: 'a\nb\n'`, and tricky strings `['yes','123','',' padded','#hash','- dash']`. Old: test/yaml.test.ts › "round-trips stringify output"
- B7. `stringify` quotes (JSON) strings that would misparse: `''`, leading/trailing space, a leading indicator (`-?:,[]{}#&*!|>'"%@\`~`), `: `, ` #`, a trailing `:`, `true|false|null|yes|no|on|off` (any case), numbers. Empty list → `[]`, empty map → `{}`, a nested list item → `-\n    - …`, a multi-line string → `|` block (`|-` when it has no final newline). A top-level scalar → `<value>\n`; top-level `[]` → `[]\n`. Old: test/yaml.test.ts › "round-trips stringify output"; exact forms from source

### yaml.ts: setIn
- B8. `setIn(src, path, value)` changes only the lines holding the value and keeps comments, blank lines and order: `setIn('a: 1   # keep\nb: 2\n', ['a'], 5)` → `'a: 5   # keep\nb: 2\n'`. Old: test/yaml.test.ts › "setIn edits one value in place and refuses what it cannot keep"
- B9. Insertions: `setIn('a:\n  b: 1\n\nc: 2', ['a','d'], true)` → `'a:\n  b: 1\n  d: true\n\nc: 2'` (no final newline added); `setIn('a:\nb: 1\n', ['a','c'], 'v')` → `'a:\n  c: v\nb: 1\n'` (children of a null map at parent + 2); `setIn('a: 1\n', ['n','m'], ['x','y,z'])` → `'a: 1\nn:\n  m: [x, "y,z"]\n'` (a missing section at the end; list items with `,[]{}` quoted); `setIn('', ['a','b'], 1)` → `'a:\n  b: 1\n'`. Old: test/yaml.test.ts › "setIn edits one value in place and refuses what it cannot keep"
- B10. Lists: `setIn('a:\n  - x\n  - y\nb: 1\n', ['a'], [])` → `'a: []\nb: 1\n'`; `setIn('a:\n- x\nb: 1\n', ['a'], ['p','q'])` → `'a:\n- p\n- q\nb: 1\n'` (keeps the dash column). Old: test/yaml.test.ts › "setIn edits one value in place and refuses what it cannot keep"
- B11. CRLF input stays CRLF: `setIn('a: 1\r\nb: 2\r\n', ['b'], 3)` → `'a: 1\r\nb: 3\r\n'`. Old: test/yaml.test.ts › "setIn edits one value in place and refuses what it cannot keep"
- B12. For both this repo's `.forge/config.yml` and `test/fixtures/config-commented.yml`, setting each editable key of `FIELDS` (`#core/config/fields.ts`) to a different valid value changes exactly that key in the parsed result (compared with `setPath` on the parsed original) and keeps every comment; the CRLF form of each file stays CRLF after `setIn(…, ['pipeline','maxRounds'], 9)`, which parses back as 9. Old: test/yaml.test.ts › "setIn edits one value in place and refuses what it cannot keep"

### zip.ts
- B13. `zip(entries)` produces an archive `unzip -t` accepts (`No errors detected`), and `unzip -p` returns each entry byte for byte, for `doctor.json`, a UTF-8 name `jobs/é/ü.txt`, an empty file, a 100 KiB compressible log and 4096 random bytes. Compressible data is deflated (method 8), random data stored (method 0): each entry uses deflate only when smaller. Old: test/zip.test.ts › "zip › unzip -t accepts it and unzip -p returns every entry exactly"
- B14. Headers: the central directory lists entries in input order; each record and its local header carry `crc` = `zlib.crc32(data) >>> 0`, uncompressed size, compressed size, the UTF-8 flag `0x0800`, and the DOS time/date of the `date` argument; the body at `offset + 30 + nameLength` inflates (or is) the data. Local signature `0x04034b50`, central `0x02014b50`, end `0x06054b50`. Old: test/zip.test.ts › "zip › headers carry crc, sizes, utf-8 flag and DOS time"
- B15. `dosDateTime(new Date(2026, 9, 16, 13, 45, 31))` → `time = (13<<11)|(45<<5)|15`, `date = ((2026-1980)<<9)|(10<<5)|16` (seconds halved, local time). Years clamp to 1980–2107. Old: test/zip.test.ts › "zip › headers carry crc, sizes, utf-8 flag and DOS time" (clamp from source)

### ansi.ts
- B16. `sanitize(s)` escapes every C0 control except `\n`, DEL, C1 and the bidi/line-separator set as visible text: `'a\x1bb\x07c\rd\te\x7ff\x9bg\u202eh'` → `'a\\x1bb\\x07c\\x0dd\\x09e\\x7ff\\x9bg\\u202eh'`; `'keep\nnewline'` unchanged; `\u2028`, `\u202a`, `\u2066` → `\\u2028`, `\\u202a`, `\\u2066`. Old: test/render.test.ts › "control characters are escaped"
- B17. `paint(false)` styles are the identity (`paint(false).bold('x') === 'x'`); `paint(true).red('x')` → `'\x1b[31mx\x1b[0m'` (bold `1`, dim `2`, red `31`, green `32`, yellow `33`, cyan `36`); `sgr(true, '1;36')('x')` → `'\x1b[1;36mx\x1b[0m'`, `sgr(false, …)` the identity. Old: test/render.test.ts › "colour: NO_COLOR, non-TTY, and alignment"

## Edge and corner cases
- E1. `parse` fails loudly with `YamlError` (message `YAML line <n>: …`, `.line` = n) outside the subset: an anchor/alias (`a: &anchor 1\nb: *anchor`) → `anchors, aliases and tags are not supported`; a tab in indentation (`a:\n\t- x`) → line 2 `tabs are not allowed for indentation`; `a: 1\na: 2` → line 2 `duplicate key "a"`; `a: "unterminated` → `unterminated string …`; `a: [1, 2] x` → `trailing characters after flow collection`; `a:\n  b: 1\n c: 2` → line 3 `bad indentation in mapping`; `x y` → `expected "key: value", got "x y"`. Setup: none (pure); check both `e instanceof YamlError` and `e.line`. Old: test/yaml.test.ts › "fails loudly outside the subset" (anchor, tab, duplicate); the other messages from source
- E2. `setIn` refuses with `YamlError` and returns nothing for: `a` in `a:\n  b: 1\n` (a block map), `a` in `a: |\n  text\n` (a block scalar), `a` in `a:\n  - name: x\n` (a list of maps), `a` with a comment between items (`a:\n  - x\n  # note\n  - y\n`), `a` with a comment after an item (`a:\n  - x  # note\n`), `a.b` inside a flow map (`a: { b: 1 }`), `a.b` behind a sequence (`a:\n  - b: 1\n`), `a.b` behind a scalar (`a: 1`). Setup: none (pure); `out` stays undefined because the call throws, and the caller's source string is unchanged. Old: test/yaml.test.ts › "setIn edits one value in place and refuses what it cannot keep"
- E3. `setIn` with an empty path → `YAML: setIn needs a key`; on a document that is a sequence → `YAML line 1: the document is a sequence, not a map`; an edit that would not parse back to exactly the intended change → `editing <path> did not produce the intended value` or `editing <path> would change other keys`. Setup: none (pure): `setIn('', [], 1)` and `setIn('- a\n', ['a'], 1)`. Old: none (from source)
- E4. `zip` refuses entry names, before writing anything, with `refusing a zip entry name with <reason>`: `a\..\..\evil` (a backslash), `../evil` and `a/../../evil` (a `..` segment), `/etc/evil` (a leading `/`), `a\x1b[31m.log`, `tab\there`, `del\x7f` (control characters), `''` (empty). Allowed: `jobs/a-1/logs/verify-test-2026.log`, `jobs/<login>/..x/~`. Setup: `data = Buffer.from('x')`, one entry per call (`zip([{name, data}])`); the two allowed names go in one call and do not throw. Old: test/zip.test.ts › "zip › refuses names that escape the extraction dir or carry control characters"
- E5. `zip` refuses what would need zip64 (`ForgeError` matching `/zip64/`): 65,536 entries, or an entry whose `data.length` is `0xffffffff` (a stand-in object, no real buffer); also a name over 65,535 bytes or a total size/offset at or past 4 GiB. Setup: `Array.from({length: 65536}, (_, i) => ({name: 'f' + i, data: Buffer.alloc(0)}))`; for the size case pass `{name:'huge', data: {length: 0xffffffff}}` cast to Buffer (rejected before any deflate). Old: test/zip.test.ts › "zip › refuses what would need zip64"

## Regressions worth keeping
- R1. Tracker and PR text rendered to a terminal could carry OSC 52 clipboard writes, title changes or cursor moves (`x\x1b]52;c;ZXZpbA==\x07y`) → every control is shown escaped; no `\x1b` or `\x07` survives. Setup: pure `sanitize('x\x1b]52;c;ZXZpbA==\x07y')`; the result contains no `\x1b` and no `\x07` byte. Old: test/render.test.ts › "control characters are escaped"
- R2. `forge config set` rewriting the whole file lost the owner's comments → `setIn` edits in place and refuses what it cannot keep, checked against every editable field on two real files. Setup: B12's two source files and per-type test values (Setup recipes). Old: test/yaml.test.ts › "setIn edits one value in place and refuses what it cannot keep"

## Cheapest layer
All in-process and pure. Only B13 shells out to `unzip` (skip when `hasBinary('unzip')` is false); B14 reads the central directory back by hand and needs no binary. B12 reads `.forge/config.yml` from the repo and `test/fixtures/config-commented.yml`.

## Setup recipes
- Central-directory reader for B14: find the last `PK\x05\x06`, read the entry count at +10 and the directory offset at +16, then per record read flags (+8), method (+10), time (+12), date (+14), crc (+16), csize (+20), usize (+24), name length (+28), local offset (+42), name at +46.
- Entries for B13: `{name:'big.log', data: Buffer.from('a line that repeats and compresses well\n'.repeat(2700).slice(0, 100*1024))}` and `{name:'random.bin', data: crypto.randomBytes(4096)}`.
- B12 test values per field type: boolean → `!default`; enum → another option; integer/number → default ± 1 within `min`/`max` (or `min + 3` when the default is null); list → `['blocker','major','nit']` with options, else `['ready','needs triage']`; `runtime.models.*` → `haiku`/`sonnet`; `tracker.github.labels.prefix` → `new-prefix:`; anything else → `new-value`. Each value must pass `validateFieldValue`.
