## Cheapest layer
Everything here is in-process against a `tempRepo()` dir with `defaults()` config: the store writes plain files and needs no `forge init`. Only these need more:
- One spawned-CLI test for the fence (B32/E7): `job set … --epoch 1` exits 3 with `--json` `error.code: 'stale_epoch'`; the per-command list (advance, step, set, agent start/end, claim) belongs to the CLI inventory, and the epoch check itself is in-process via `setJob`/`recordAgent`/`claimJob` with `fence`.
- One spawned-CLI test for `job claim` exit 3 / `error.code: 'owned'` (B25) if the CLI inventory does not own it.
- B19 (focus cleared on finish) can be in-process: `setFocus(root, id)` then `setJob(root, id, {state:'done'})`, then check focus.json is gone and the last event.
- B93/E23 FIFO/symlink cases need POSIX (`mkfifo`); run the FIFO open in a child with a timeout so a regression fails instead of hanging.
- The 4-process lock contention lives in core.os, not here.
Scratch git repos are needed only where `createJob` resolves a GitHub slug (`localRepoSlug`) — use `tracker.github.repo: 'o/r'` in config so no remote is read.

## Setup recipes
- Repo: `tempRepo()` from `test/helpers.ts` (git repo with one commit; `FORGE_ROOT` pins the CLI). Config: `defaults()` from `#core/config/load.ts`; for GitHub ids set `config.tracker.kind = 'github'; config.tracker.github.repo = 'o/r'`.
- Job: `createJob(root, defaults(), { title: 'X' })`; a child with `parent`; a retro with `kind: 'retro'`.
- Planting state behind the store: read `<root>/.forge/jobs/<id>/job.json`, mutate, write back with `fs.writeFileSync` (e.g. `lease.expiresAt = <15 min ago>`, `lease.renewedAt = '2020-01-02T03:04:05.000Z'`, `dependsOn`, `kind`). An expired lease: `{driver:'A', epoch:1, since, renewedAt:<45 min ago>, expiresAt:<15 min ago>}`. Or `updateJob(root, id, j => { j.lease.expiresAt = … })` (does not renew).
- Byte-identical checks: compare `fs.readFileSync(job.json)` (and `events.jsonl`) Buffers before/after; for "nothing written" snapshot every path under the job dir.
- Old-version job fixtures: write job.json with a literal old `schemaVersion` and mark the line `// old-version fixture` (test/schema.test.ts enforces this outside itself), e.g. `{schemaVersion:16, id:'old-job', title:'Old', state:'running', owner:{session:'S-old', host:'laptop.local', since:'2026-10-01T10:00:00.000Z', heartbeat:'2026-10-01T11:00:00.000Z'}}`.
- Reviews: write `review/round-<n>/<lens>.md` under the job dir; mark reviewers started/ended with `recordAgent(root, id, {role:'reviewer:code', phase:'start'|'end'}, config)`; an integration conflict with `logEvent(root, id, 'integrate-conflicts', {strategy:'merge', conflicts:['a.ts'], behind:1})` and `sleepSync(5)` (`#core/os/process.ts`) between timestamps.
- Known secrets for B43: `recordKnown(root, id, { K: value })` from `#engine/guard/known-secrets.ts`, then `logEvent`.
- Requests: `enqueue(root, null, {type:'resume', job})`, `claimRequest(root, rid, 'S')`; age a claim by rewriting `updatedAt` in `.forge/runtime/requests/<rid>.json` or pass `at: Date.now() + 31 * 60_000`.
- Session log pages: write `.forge/runtime/daemons/<scope>.log` and open with `openRead`; call `readLogPage(fd, fs.fstatSync(fd).size, logBase, { before })`.
- Transition hook: `const remove = onTransition((root, job, from, to) => calls.push(to))` (from `transitions.ts`), and `remove()` in `finally` (the list is module-global, so keep such a test out of concurrent blocks).
- Archive records for E21: write `.forge/archive/<id>.json` as `{archiveVersion:1, id, archivedAt, trigger:'cli', job:{…, id}, events:[], summary:{}}` with no live job dir.
