## Edge and corner cases
- E1. `deepMerge` refuses, with `ForgeError` code `usage` and message `<label> key "<key>" is not allowed`, before copying anything: `{"__proto__":{"polluted":1}}` as over (label `merge source`), `{"a":{"constructor":{"prototype":{…}}}}` (`constructor`), `{"a":[{"b":1},{"__proto__":…}]}` (inside a list), `{"a":{"prototype":1}}`, and the same in base (label `merge base`, e.g. `{"a":[[{"constructor":1}]]}`). Custom labels: `{over:'config sink values'}`, `{base:'defaults'}` appear in the message. `({}).polluted` stays undefined. Setup: none (pure); build each hostile input with `JSON.parse` so the key is an own property, call `deepMerge(base, over)` (or with `{over:'config sink values'}` / `{base:'defaults'}` labels), and check `({}).polluted` is undefined afterwards. Old: test/shape.test.ts › "deepMerge merges into a copy and refuses prototype keys"
- E2. Nesting deeper than 64 levels (5000 nested `{a:…}`) → `ForgeError` code `usage` `merge source is nested more than 64 levels deep` (or `merge base …`), never a RangeError. Setup: `let deep = {}; for (let i = 0; i < 5000; i++) deep = {a: deep}`; `deepMerge({}, deep)` (label `merge source`) and `deepMerge(deep, {})` (label `merge base`). Old: test/shape.test.ts › "deepMerge merges into a copy and refuses prototype keys"
- E3. `setPath` with `__proto__.x`, `a.constructor.prototype.x` or `a.prototype` → `ForgeError` code `usage` (`"<path cut to 80>": __proto__, constructor and prototype are not path segments`), the object unchanged, no prototype write; `getPath` with those paths, or `__proto__`/`constructor` on `{}`, → undefined. Setup: `obj = {a: {}}` per path; after the throw `obj` still deep-equals `{a: {}}` and `({}).x` is undefined; `getPath({a:{prototype:1}}, path)` → undefined. Old: test/shape.test.ts › "setPath and getPath refuse prototype segments"
- E4. `assertSafeRef` refuses `a;b`, `a$(b)`, `a|b`, ``a`b` ``, `a{b}`, `-x`, `a b`, `a\nb`, `''`, 201 chars, `true`, `null`, `undefined` → `ForgeError` whose one-line message starts `<field> ` and contains `is not a safe branch name` (`job.base undefined is not a safe branch name…`); the shown value is JSON cut to 80 chars (`f "xxx…` with 79 x's). Setup: none (pure); `field` = `'job.branch'` (and `'job.base'` for undefined); the message has no newline. The long case: `assertSafeRef('x'.repeat(300) + ';', 'f')` → message starts with `f "` followed by 79 `x` and ` is not`. Old: test/safe-ref.test.ts › "assertSafeRef accepts plain branch names and refuses shell metacharacters"
- E5. `coerce` of a `[`/`{` value that is not JSON → `ForgeError` exit 2: `coerce('[code,tests]','reviewers')` → `--field reviewers: "[code,tests]" is not valid JSON; quote it for the shell, e.g. --field 'reviewers=["code","tests"]'`; `'[ a , , b ]'` (services) suggests `--field 'services=["a","b"]'`; `'[[x]'` suggests `["a","b"]`; `'{k:v}'` (meta) suggests `{"k":"v"}`; no key → `--field value: …`; a 10,000-char value gives a message under 200 chars. Setup: none (pure); the error is `ForgeError` code `usage`, `exitCode 2`. Old: test/args.test.ts › "coerce: unparseable JSON throws with the quoted form; other values coerce as before"
- E6. `shellArgs` refuses a quote, backslash or control character (`nul\0`, `del\x7f`, `\x01`) → `forge run: argument <i> contains a quote, backslash or control character (got <json>)` (i is 1-based). Setup: none (pure); `shellArgs(['ok', bad])` names argument 2. Old: test/run-args.test.ts › "unsafe args, args without -- and args with --background are refused before anything runs"
- E7. `splitWords` with an unterminated `'` or `"` → `ForgeError` `<label>: unterminated ' in "<template>"` (or `"`). Setup: none (pure), e.g. `splitWords("a 'b", 'daemon.command')` → `daemon.command: unterminated ' in "a 'b"`. Old: none (from source)
- E8. `resolveWorktreePaths` refuses `src/.git/x` (`inside .git`, any case of `.git`), `..` and anything resolving outside through a symlinked parent (`… is outside the job's worktree <top>`), and `''` or a NUL (`invalid path …`). Setup: B11's temp worktree dir (a realpath'd `mkdtemp` with `src/`); for the outside-through-symlink case add `fs.symlinkSync(<another temp dir>, '<dir>/out')` and pass `out/x`. Nothing is created on disk. Old: test/git-commit.test.ts › "argument and path helpers"
- E9. `slugify('')` or text with no alphanumerics → `'job'`. Setup: none (pure); also `slugify('!!!')` → `'job'`. Old: none (from source)

## Cheapest layer
All in-process. Only B9 needs a real git scratch repo (`tempRepo()` plus `git worktree add`) and must clear `FORGE_ROOT` for the no-override case; run it outside concurrent blocks because it changes `process.env`. B11/E8 need a temp dir and, for the symlink case, POSIX.

## Setup recipes
- `tempRepo()` from `test/helpers.ts` for B9; create a worktree with `repo.git('worktree', 'add', '<dir>', '-b', 'x')` and call `mainRoot(<worktree dir>)` with `delete process.env.FORGE_ROOT` (restore after).
- B11/E8: `fs.realpathSync(fs.mkdtempSync(os.tmpdir() + '/forge-paths-'))`, `mkdir src`, `symlinkSync('/etc/hosts', '<dir>/link')`.
- Pollution checks: build hostile inputs with `JSON.parse('{"__proto__": …}')` (an object literal would set the prototype instead of an own key) and assert `({} as any).polluted === undefined`.
