## Cheapest layer
Everything here is in-process: import the module from `dashboard/src/lib/*.ts` (Node strips the types) and call it. No item needs a spawned CLI, the HTTP server, a scratch repo or a stub `claude`. A few need injected seams rather than real systems:
- The `post*`/`fetch*` wrappers (daemon, effort, environment, focus, permissions, repo-proposals) take a `fetchImpl` argument; pass an async function that records `(url, init)` and returns `new Response(body, {status})` or `{ok, status, statusText, text: async () => body}`.
- `createSessionLog` (daemon-log.ts) takes `connect`, `fetchPage`, `visible`, `now`; only the custom-`urls` item uses the global `fetch`, so swap `globalThis.fetch` and restore it in `finally`.
- `startTicker` (live.ts) takes `{doc, setInterval, clearInterval, now}`.
- theme.ts and `motion()`/`prefersReducedMotion` read `document`, `localStorage` and `matchMedia` globals: install stubs with `Object.defineProperty(globalThis, k, {value, configurable:true, writable:true})` and restore the saved descriptors (reading Node's own `localStorage` getter warns). Those tests must not run inside `describe(…, {concurrency})`.
- Time: `ago`, `budgetPanelModel`'s checked line and `restartPending`-style checks read the wall clock unless given `now`; pass a fixed `now` where the API takes one.
Cross-checks against the engine import its public modules from test code: `#engine/metrics/budget.ts` (`effectiveLimits`), `#core/config/load.ts` (`defaults`, `resolveEffort`), `#core/config/fields.ts` (`FIELDS`), `#core/job/schema.ts` (`API_VERSION`, `STAGES`, `STATES`, `WAITING_ON`, `EFFORTS` via the effort module), `#engine/pipeline/deps.ts` (`DEP_REASON`), `#integrations/github/preview.ts` (`parseGitHubUrl`). The config-form error keys live in `dashboard/src/messages/en/settings.json` and must exist there.
