Baseline coverage: not measured (outside `lib/` and `dashboard/src/lib/`, which `npm run coverage` covers)

Tests can't import or render `.svelte` components (runes need the compiler), so the views and components have no behaviour tests of their own: their logic is tested through the plain-TS models in dashboard.lib.md, and their markup is held only by the kept invariants below. Tests marked BUILT read the real `dashboard/dist/` and skip without it (`noDist()` in `test/dist.ts`); CI sets `FORGE_REQUIRE_DIST=1` so they run there.

## Edge and corner cases
- E1. Setup: the B1 bootstrap harness on dashboard/index.html, but with `localStorage: {getItem: () => { throw new Error('denied') }}`, `matchMedia: () => ({matches:false})` and an empty `dataset`. Storage whose `getItem` throws (some private modes): the inline bootstrap sets nothing, so `dataset` stays `{}` and `<html>` keeps its shipped `data-theme="forge"` (CSS defaults: forge, grain on). Old: test/dashboard-theme.test.ts › "dashboard/index.html inline script agrees with normalizeTheme"
- E2. Setup: the B1 harness and table (rows `Forge,T`, `Temper,T`, `system,F`). The bootstrap is case-sensitive like `normalizeTheme`: `'Forge'` and `'Temper'` fall through to the OS theme (`ash` on a light OS), and `'system'` behaves as unset. Old: test/dashboard-theme.test.ts › "dashboard/index.html inline script agrees with normalizeTheme"
## Regressions worth keeping
- R1. The inline bootstrap duplicates `normalizeTheme`/`grainOn`/`screenOn` (it must run before the bundle and the stylesheet to avoid a flash of the wrong look); B1/B2 run both over the same table so the two copies cannot drift, including the legacy Drafting ids (`cyanotype`, `nightprint`, `vellum`) and pre-Drafting ids (`dark`, `light`) and the old `forge.paper` fallback for grain. Old: test/dashboard-theme.test.ts › "dashboard/index.html inline script agrees with normalizeTheme"
## Cheapest layer
- B1, B2, E1, E2: read `dashboard/index.html` (and `dist/index.html` when built) and run its single inline script in `node:vm` with stubbed globals; no browser, server or build needed for the source copy.
- B3, B4: `sourceHash`/`distHash` over a temp directory tree (a fake `dashboard/` with `dist/assets/`, `node_modules/`, a `package-lock.json`); no Vite, no git.
- B5, B6: read files of the real build; they need `npm run build:dashboard` (skip via `noDist()` otherwise).
- B7: read `package.json` and `package-lock.json`.
- No item needs a spawned CLI, the HTTP server or a stub `claude`. Serving dist (the manifest allowlist, `__FORGE_TOKEN__` substitution, no-store) is the server inventory's; the "dashboard/dist is stale" release check (`releaseProblems`, `--dist present|absent`) and the main-update commit are the release/scripts inventories' (test/release-check.test.ts, test/main-update.test.ts); `test/release-workflow.test.ts` is kept and belongs to the release inventory.
## Setup recipes
- `test/dist.ts` (kept): `DIST` (the real `dashboard/dist`), `noDist()` (skip reason, or false when built or when `FORGE_REQUIRE_DIST=1`), `NOT_BUILT_SKIP`, and `FIXTURE_DIST` (`test/fixtures/dist/`, the server's hand-written dist). Use `{ skip: noDist() }` on every BUILT test.
- `test/svelte-markup.ts` and `test/built-css.ts` (kept): the bracket/string-aware markup scanner (`CLOSE`, `endOf`, `literals`, `markup`, `soleCall`, `tags`) and `builtCss()` (the manifest's stylesheets joined, minifier spacing normalised) that the kept `dashboard-invariants.test.ts` imports. The kept test also imports `isPlural` (dashboard/src/lib/i18n.ts), `TONE_CLASS` (dashboard/src/lib/util.ts) and `THEMES` (dashboard/src/lib/theme.ts): those exports must stay.
- Bootstrap harness: `const scripts = [...html.matchAll(/<script>([\s\S]*?)<\/script>/g)].map((m) => m[1])` (expect length 1); `vm.runInContext(scripts[0], vm.createContext({ localStorage: { getItem: (k) => store[k] ?? null, setItem: (k) => writes.push(k), removeItem: (k) => writes.push(k) }, matchMedia: (q) => ({ matches: q === '(prefers-color-scheme: light)' ? light : false }), document: { documentElement: { dataset } } }))`.
- build-stamp tree: `mkdtemp`; `dashboard/app.js` (`'export {};\n'`), `dashboard/dist/assets/index-x.js`, `dashboard/node_modules/`; lockfile `{packages:{'':{version:'1.0.0'}, 'node_modules/vite':{version:'7.3.7', resolved:'r'}}}`; remove the temp dir in `finally`.
- `manifestFiles(distDir)` and `ASSET` come from `scripts/main-update.ts`.
