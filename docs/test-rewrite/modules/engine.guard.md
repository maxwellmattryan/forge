- Names used by the items: **gate scratch** = the gate recipe below (default tracker `local`, no remote; nothing reaches `gh` except where a fake `gh` is put on PATH); **protected scratch** = the same template plus the protected extras (`notes.txt`, `.forge/secrets-allow.txt`, `package-lock.json`, `MARK_CMD`); **remote recipe** = the pr open bullet (fake logging `gh` that exits 1, bare remote holding main, `GIT_SSH_COMMAND=false`); **race recipe** = the stand-in `git` and `gh` in that bullet; **`jobRepo`** = the integrity helper.
