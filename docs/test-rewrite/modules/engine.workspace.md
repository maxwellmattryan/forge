## Setup recipes
- Scratch repo: `repoTemplate` + `forge init write --answers <file>` with `{ commands:{…}, verify:[…], worktrees:{ root:'../{repo}.wt' }, tracker:{ kind:'none'|'local' } }`, commit; remove `<repo>.wt` on cleanup. Jobs: `forge job new --title …` (or `tracker create` + `next --claim --session s1`), `forge worktree create <id>`, `forge job round <id>` (or in-process `createJob`, `createWorktree`, `updateJob(root, id, j => j.round = 1)`).
- Names used by the items: **verify-groups scratch** = the concurrency recipe below (base answers `{ tracker:{ kind:'none' }, worktrees:{ root:'../{repo}.wt' } }`, `rv.mjs` committed, jobs created in-process in round 1, `forge verify` spawned); **e2e scratch** = the e2e recipe; **checkout scratch** = the checkout recipe (answers also `tracker:{ kind:'local' }`, `pr:{ enabled:false }`, `ports:{ base: random 20000-40000, span:10 }`); **regeneration fixture** = the regeneration recipe; **server-focus scratch** = a started server (`startServer(root, { port:0, distDir: FIXTURE_DIST })`, token from the page's `forge-token` meta) over a repo initialised like the checkout scratch.
- Verify concurrency: commit a small `rv.mjs` that marks `<name>.start`/`<name>.done` in a temp dir and supports `--needs X,Y` (fail unless done), `--meet A,B` (wait up to `--within` ms, default 10000, for their starts), `--after X` (wait for X's `command` event in `{root}/.forge/jobs/{job}/events.jsonl`), `--fail`; step command `node rv.mjs '<markers>/{job}' '{root}/.forge/jobs/{job}/events.jsonl' <name> <flags>`. Write config via `stringifyConfig(deepMerge(defaults(), …))` to allow invalid verify lists.
- e2e: config `{ commands:{ test:'true', e2e:'echo E2E-RAN' }, verify:['test'] }`; jobs commit `web/app.css` (UI) or `lib/x.mjs` (not UI).
- Integrity through verify: commit `test/a.test.mjs` (2 tests), `test/b.test.mjs` (1), `package.json` with `scripts.test` on main; answers with `policy: { protectedPaths: [] }` so committing `.forge/config.yml` reaches integrity; switch modes with `init write --answers {verifyIntegrity:'block'}`.
- Safe refs: `setJob(root, id, { owned: { branch | worktree | base: <value> } })`; check no `pwned`/`out.txt` in the worktree or repo and no `background-start` event.
- Checkout: answers with `commands { on: 'echo "on $FORGE_JOB" >> {root}/.marker', off: …, evil: …, gate: 'test "$FORGE_JOB" != beta' }`, a `<repo>.fixed/plugin` target, jobs created with `--ref alpha|beta` whose worktree has `out/plugin`; record at `checkoutFile(root)` (`runtime/checkout.json`). POSIX only (symlinks, sh).
- Focus: `focusFile(root)` (`runtime/focus.json`) from `#core/job/focus.ts`; archive a done job with `archiveJob(root, id, 'cli', { config })`.
- Editor: `fakeBin('stub-editor')` on PATH (records argv; `.calls()`), `FORGE_EDITOR` set per case (tests touching `process.env` run serially).
- Dev server proof: `test/fixtures/dev-server.mjs`, detached `sleep 30` processes as planted pids written to `runtime.json` `{ dev: { pid, startedAt } }`; a pty-holding process via `script -q /dev/null sleep 30` (macOS) / `script -qfec 'sleep 30' /dev/null` (Linux).
- Regeneration: repo with `gen.mjs` (builds `dist/out.txt` from `src/*.txt` plus one content-hashed `dist/assets/<sha8>.txt`, deleting older ones, appending to `.gen-runs`), `bad.mjs` (writes `dist/junk.txt`, prints `BUILD-BROKE on purpose`, exits 3), `src/a.txt`, `.gitignore` `.gen-runs`; config `commands { gen:'node gen.mjs', bad:'node bad.mjs', test:'true' }`, `worktrees { generated:['dist/**'], generatedBy:'gen' }`; each side adds a source, rebuilds and commits; run `forge integrate` with `GIT_EDITOR=true`. For the argv check, a `fakeBin`-style `git` wrapper that logs argv (`\x1f`-separated) and execs the real git.
- Daemon env: `{ FORGE_DAEMON:'1', [TRUST_ENV]: trustDigest(root), FORGE_DAEMON_SCOPE:<id> }`; `sessionEnv(...)` from `#integrations/claude/argv.ts` for git pins.
