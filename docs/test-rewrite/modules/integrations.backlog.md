## Cheapest layer
All in-process: import the default export and call it with `ctx = {root, config: defaults()}` against a `.forge/backlog.md` in a `tempRepo` (path from `config.tracker.local.path`). Behaviour through the loader (secret guard, `forge tracker …`) is in engine.trackers.md.
## Setup recipes
- Format: one item per top-level `- [m] Title[ → job-id]` line, `m` ∈ ` ` ready, `~` in-progress (claimed), `x` done, `-` dropped, `?` needs-info; indented (2+ spaces) contiguous lines are the body; a body line starting `Needs info: ` is Forge's note, never body; ref = slug of the title (survives reordering).
- Fixtures used: `# Backlog\n\n- [ ] First thing\n  with a description\n- [x] Old thing\n`; and `# Backlog\n\n- [?] Vague thing\n  some words\n  Needs info: a clear outcome\n- [ ] Clear thing\n  line one\n  line two\n- [~] Taken thing → job-1\n- [x] Done thing\n- [-] Dropped thing\n`. Jobs from `createJob(root, config, {title, issues:[{tracker:'local', ref, url:null}]})`.
