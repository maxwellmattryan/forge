## Behaviours

### Pricing
- B1. `pricing(overrides)` returns pricing.json merged with `config.usage.pricing`: `aliases`, `models` and `blend` are each shallow-merged (an override model adds to or replaces one entry, keeping the rest); other keys (`asOf`, `source`, `notes`) pass through. The file is read once per process. Old: none direct (from source); spend.test.ts re-prices with an override model (B5)
- B2. `resolveModel(model, table)`: falsy → `null`; lowercased exact model id (`'claude-opus-5-5'`) → itself; an alias (`'opus'` → `'claude-opus-5-5'`, `'sonnet'` → `'claude-sonnet-5-5'`, `'haiku'` → `'claude-haiku-5-5'`, `'fable'` → `'claude-fable-5-1'`); a dated id whose undated form is known (`'claude-sonnet-4-6-20250101'` → `'claude-sonnet-4-6'`, the suffix is `-` + 8 digits); anything else → `null`. Old: none direct (from source; jobs.test.ts resolves `'opus'` through it, B4)
- B3. `estimateCost(u, overrides)` → `{usd, model, method}`: an unknown model → `{usd: 0, model: u.model ?? null, method: 'unpriced'}`; with any of input/output/cacheRead/cacheWrite > 0 → `method: 'exact'`, `usd = (input·rate.input + output·rate.output + cacheRead·rate.cacheRead + cacheWrite·rate.cacheWrite) / 1e6`, `model` the resolved id; otherwise `method: 'blended'`, `usd = totalTokens × (blend.input·rate.input + blend.output·rate.output + blend.cacheRead·rate.cacheRead + blend.cacheWrite·rate.cacheWrite) / 1e6` with pricing.json's blend `{input:0.03, output:0.02, cacheRead:0.85, cacheWrite:0.1}`. Example: opus (claude-opus-5-5: input 4, output 20, cacheRead 0.2, cacheWrite 5 per M) with `{input:1000, output:2000, cacheRead:100000, cacheWrite:5000}` → `(4000 + 40000 + 20000 + 25000)/1e6 = 0.089`. Old: none direct (from source)
- B4. `[module: core/job/store]` `recordAgent` start `{model:'opus'}` then end `{usage:{input:1000, output:2000, cacheRead:100000, cacheWrite:5000}}` → `usage.totalTokens: 108000` and `usage.byModel['claude-opus-5-5'].estCostUsd > 0` (the alias resolves to its id). Old: jobs.test.ts › "job lifecycle: ids, transitions, claims, usage, verdict policy"
- B5. `[module: engine/metrics/spend]` a `usage.pricing.models['usd-model'].input` change (1 000 000 → 2 000 000 per M) re-prices every event in the spend ledger. Seed: `dollarConfig()` (`usd-model` $1 per input token), job A `spend(root, a, 1, '2026-10-10T00:00:00.000Z')`, job B `spend(…, 2, same ts)` and `spend(…, 4, '2026-10-10T01:00:00.000Z')`, an archive record `.forge/archive/arch.json` `{archiveVersion, id:'arch', job:{…state:'done'}, events:[], summary:{usage:{totalTokens:1, estCostUsd:3}}}`; `periodTotals(spendLedger(root, c), Date.parse('2026-10-10T12:00:00Z')).monthUsd` = 10, and with input repriced to 2 000 000 → `2·7 + 3 = 17` (the summary-only record keeps its total; 3 events re-parsed); the pricing digest changes with the override. Old: spend.test.ts › "cache reuse and rebuild"
- B6. pricing.json's `asOf` is what `/api/about` reports as `pricingAsOf`. Old: server.test.ts › "GET /api/about reports versions" (owned by the server inventory)

- B10. Lookups never scan other project dirs: the same files under `<projects>/-some-other-repo/…` are not found (`null`). Old: transcripts.test.ts › "never scans other project dirs"
- B11. `openTranscript(hit, projects)` → `{fd, size, mtimeMs, path}` for a regular file whose realpath sits inside `hit.dir`, where `hit.dir` resolves to exactly `<realpath(projects)>/<slug>`; the caller closes `fd`. Old: transcripts.test.ts › "openTranscript confines to the hit's slug dir"
- B12. `lastActivity(fd, size, {worktree?, root?})` reads at most the last 64 KiB and returns, from the newest `assistant` line, its last `tool_use` as `{kind:'tool', text:'<Tool> <target>', at:<timestamp>}` or else the first non-blank line of its last text block as `{kind:'text', …}`: a Read of `<wt>/lib/server.ts` with `worktree: wt` → `'Read lib/server.ts'` (a later `user` tool_result doesn't hide it); Bash `'npm test\n--more'` → `'Bash npm test'`; an Edit of `<realpath(root)>/lib/a.ts` with an unresolved `root` → `'Edit lib/a.ts'`; Grep `{pattern:'foo', path:'/x'}` → `'Grep /x'` (target key order: file_path, notebook_path, path, pattern, command, url, query, description, skill); text `'\n  All   checks\tpass.  \nSecond line'` → `'All checks pass.'`; 100 × `'word '` → 160 characters ending `…`; markup (`<script>alert(1)</script>`) is returned verbatim as text. Old: transcripts.test.ts › "lastActivity summarises the tail"
- B13. `cachedActivity(hit, projects, opts)` gives the same answer as `lastActivity` (cached by path, size, mtime, worktree and root; at most 64 entries) and `null` for a hit it can't open. Old: same test

## Edge and corner cases
- E1. A forged worktree adds no other repo's project dir (`transcriptProjectDirs` → own dirs only) for: another repo (`<base>/other-repo`), a path inside it, its worktrees dir (`other-repo.worktrees/153-job`), a traversal out of ours (`repo.worktrees/../other-repo`), the worktrees dir itself, a relative path (`'relative/wt'`), and `root`; a worktrees entry symlinked into another repo (`repo.worktrees/sneaky → other-repo`) is refused too; and the other repo's transcripts are never returned by `agentTranscript`/`ownerTranscript` with that worktree. Setup: the transcript scratch (Setup recipes), `transcriptProjectDirs(root, {id:'153-job', worktree:<forged>}, projects)`; for the lookups, write `<projects>/<slug(other)>/<OWNER>/subagents/agent-abc123.jsonl` and `<OWNER>.jsonl` and pass `job({worktree: other})`. Old: transcripts.test.ts › "a forged worktree adds no other repo's project dir"
- E2. Ids are checked before they become path segments: a lease driver / run session that isn't a uuid (`'not-a-uuid'`) → `ownerTranscript` and `agentTranscript` `null` (even when `not-a-uuid.jsonl` exists); agent ids `'../x'`, `'a/b'`, `''`, 101 × `'x'`, `'..'` → `null` (`AGENT_ID` = `/^[A-Za-z0-9_-]{1,100}$/`). Setup: transcript scratch with `<slugDir>/<OWNER>/subagents/agent-abc123.jsonl`, `<slugDir>/not-a-uuid.jsonl`, `<slugDir>/not-a-uuid/subagents/agent-abc123.jsonl`; job `lease.driver: 'not-a-uuid'`, `runs: [{session:'not-a-uuid'}]`; for agent ids, `agents: {r: {runs:1, agentId:<bad>}}`. Old: transcripts.test.ts › "rejects traversal, symlinks and non-files"
- E3. Symlinks and non-files are refused: an agent transcript symlinked to a file outside the projects dir → `null`; symlinked to another project's file → `null`; a slug dir that is itself a symlink to elsewhere → both lookups `null`; a FIFO in place of the file → `null`, and `openTranscript` on it returns `null` without hanging (`O_NONBLOCK`, then fstat); a directory named `agent-dir1.jsonl` → `null`; `openTranscript({path:<outside file>, dir:<slugDir>})` → `null`. Setup: transcript scratch; outside file `<base>/secret.jsonl`; links created with `fs.symlinkSync`; a second scratch whose `slugDir` is a symlink to `<base2>/elsewhere`; FIFO via `mkfifo` (POSIX). Old: same test
- E4. `openTranscript` confines to the hit's own slug dir: a file in another slug dir under the same projects dir → `null`; a link in our slug dir to another project's file → `null`; a `dir` that isn't a slug directly under the projects dir (`<slugDir>/<session>`, or the projects dir itself) → `null`; a slug dir swapped for a symlink after the lookup → `null` at open (the target file untouched). Setup: transcript scratch with `mine` under `slugDir` and `theirs` under `<projects>/-other-repo/<OWNER>/subagents/`; call `openTranscript({path, dir}, projects)` directly and close any returned fd. Old: transcripts.test.ts › "openTranscript confines to the hit's slug dir"

## Cheapest layer
- In-process with a temp dir (no repo needed for most): every transcripts.ts function. Build `projects` as `<tmp>/claude/projects` and pass it explicitly (`{projects}`), and pass `worktrees` when the test shouldn't depend on a repo config. Pricing is pure.
- Usage import: in-process `importClaudeCodeTranscript` with `projectsDir`; one spawned CLI test for `forge job agent end --import` (B16) with `HOME` set to a fake home whose `.claude/projects/-scratch/session-1/subagents/agent-<id>.jsonl` holds the transcript.
- HTTP server (`startServer(root, {port:0, distDir, projectsDir, sseMaxAgeMs})`): B17–B20, E6, E7 only; they belong in the server's integration tests.

## Setup recipes
- Transcript scratch: `base = mkdtemp`, `root = <base>/repo` (not realpath'd, so on macOS its realpath differs), `projects = <base>/claude/projects`, `slugDir = <projects>/<projectSlug(root)>`. Job shape (no repo needed): `{id:'153-job', lease:{driver:'11111111-2222-4333-8444-555555555555', epoch:1, …}, runs:[{session:'66666666-7777-4888-8999-aaaaaaaaaaaa'}, {session:<owner>}], agents:{'reviewer:code':{runs:1, status:'running', agentId:'abc123'}, builder:{runs:1, status:'done', agentId:'old999'}}, worktree:null}`. Files: `<slugDir>/<session>/subagents/agent-<agentId>.jsonl`, `<slugDir>/<driver>.jsonl`. Assistant lines: `{"type":"assistant","timestamp":"2026-10-15T10:00:00.000Z","message":{"content":[{"type":"tool_use","name":"Read","input":{"file_path":"…"}}]}}`. A FIFO with `mkfifo` (POSIX only).
- Usage fixture: `test/fixtures/transcript-resumed.jsonl` (9 lines: one builder transcript, round 1 then a resume whose prompt contains `Rework round 2`); split it at that line to build round-1-only and round-2-only files. Agent id `a1b2c3d4`.
- Server routes: `tempRepo()`, a job claimed by the owner uuid, `recordAgent` builder start/end (backdate its times with `updateJob` so start order is stable), `reviewer:security` start with model `opus` and `attachAgent(root, id, 'reviewer:security', 'abc123')`; the dist fixture under `test/fixtures/dist/`; read the token from the served page's `<meta name="forge-token" content="…">`; send `x-forge-token` and `origin: http://127.0.0.1:<port>`.
- Pricing: call `pricing({models:{'usd-model':{input:1_000_000, output:0, cacheRead:0, cacheWrite:0}}})` (as `test/repo-budget-fixture.ts` `dollarConfig()` does) to get exactly $1 per input token.

## Dropped on purpose
- server-transcripts.test.ts's SSE frame-parsing helper and the exact page size of 1000 are server internals; keep "pages backwards with `more` and `before`" (B19) and pin only what the dashboard relies on.
- integration/server/secrets.test.ts imports `projectSlug` only to place a fixture transcript; its tests are the server's redaction cases, owned by the server inventory.
- model.test.ts, scoring.test.ts and roster.test.ts call a different `resolveModel` (the role-model resolver in core/config), not pricing's.
