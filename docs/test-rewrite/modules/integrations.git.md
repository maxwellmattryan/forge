## Edge and corner cases
- E1. (gap, no old test) `slugFromRemote(url, host)`: scp form on another host → null; `ssh://`, `git://`, `http(s)://` accepted only when the hostname equals `host` (case-insensitive); a path with other than 2 segments → null; an owner or name failing `SEG` (`/^[A-Za-z0-9][A-Za-z0-9._-]{0,99}$/`) or a name containing `..` → null; a trailing `.git` and slashes are stripped; `GH_HOST` changes the host `localRepoSlug` and `githubHost()` use. `localRepoSlug` reads the remote once per root per process (a later remote change is not seen). In-process, pure for `slugFromRemote`; `localRepoSlug` parts need a `tempRepo` with an origin; untested in the old suite. Old: none
- E2. (gap, no old test) `historyEnv()` adds `GIT_NO_REPLACE_OBJECTS=1` and `GIT_GRAFT_FILE=<devnull>/forge-no-grafts` to `gitEnv()`; `git()` errors name the caller's args, not the pins (`shownArgs`); `allowFail` returns `{ok:false, status, …}` instead of throwing. In-process (`historyEnv`, `git` with `allowFail` in a `tempRepo`); untested in the old suite. Old: none

## Cheapest layer
- In-process, no repo: B1–B3 (`gitInvocation`, `gitEnv`), E1 (`slugFromRemote`), E2's env shape, B7's `sessionEnv` shape (office/session's function; keep it where sessionEnv is tested if the office inventory takes it).
- A `tempRepo` scratch repo: B4–B6 (fsmonitor hook, inherited `GIT_DIR`), B7's hook-runs control, B8 (repos with remotes added; the gh stub only proves it is never called).
- No spawned CLI or server needed.

## Setup recipes
- Set inherited variables by assigning `process.env` around the call and restoring after (not in a concurrent describe).
- fsmonitor: write an executable `#!/bin/sh\necho ran >> '<marker>'` outside the repo, `git config core.fsmonitor <hook>`, modify `README.md`, confirm a plain `git status --porcelain` creates the marker, delete it, then call the wrapper.
- Hooks path: `mkdir .githooks`, an executable `pre-commit` that touches a marker, `git config core.hooksPath .githooks`, `git commit --allow-empty -m x` with `sessionEnv(process.env)` vs `process.env`.
- `localRepoSlug`: four `tempRepo()`s; `git remote add origin <url>` on two; a `gh` sh stub on PATH that appends to a log and prints `stub/repo`; assert the log never exists. Config from `defaults()`.
