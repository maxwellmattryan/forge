Baseline coverage: 99.3% overall (1749/1762); `start.ts` 99.3%

Since #400 the server is the machine dashboard: `startServer({ home, port: 0 })` serves every project registered in `home` (test/support/machine-server.ts `serveProjects`), the routes are two tables, `ROUTES` (the page, assets, `/api/about`, `/api/projects`, `/api/projects/events`) and `PROJECT_ROUTES`, and every project route below lives under `/api/p/<project>/`: read a path such as `/api/state` here as `/api/p/<project>/state` (the bare path is 404). Streams are keyed `<project>/<scope>`. Machine-server behaviour (one server for two projects, the machine cap, registration while running, `/api/projects`) is in test/integration/server/machine.test.ts.

Conventions used below. "good headers" = `{ 'x-forge-token': <token>, origin: 'http://127.0.0.1:<port>', 'content-type': 'application/json' }` with `host: 127.0.0.1:<port>`. "JSON error" = status as given, `Content-Type: application/json; charset=utf-8`, `Cache-Control: no-store`, body `{ "error": string }`. "text 403/404/415" = `Content-Type: text/plain` with the literal body given. Every response carries `X-Content-Type-Options: nosniff`; no response carries `Access-Control-Allow-Origin`.
