# Docs lens

Check:
- README, docs site, CHANGELOG, inline API docs and examples reflect the change.
- New config, env vars, commands or flags are documented where users look for them.
- Agent instruction files (AGENTS.md / CLAUDE.md) are updated if conventions or commands changed.
- No stale references to renamed or removed things.

Missing docs for user-facing behaviour → major; typos → nit.
