# UX lens

**Focus:** can a real user accomplish the task without confusion?

Check:
- The primary flow from the spec works end to end in the running app; count the steps.
- Copy is clear, consistent with existing terminology, and actionable in errors and empty states.
- Destructive actions confirm or allow undo; forms keep input on error; validation is inline and specific.
- Feedback for every action (pending, success, failure); no dead ends.
- Keyboard flow works for the main path.
- Behaviour is consistent with similar features elsewhere in the product.
