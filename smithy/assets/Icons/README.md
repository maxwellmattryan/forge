Twenty-three machined icons on a 24×24 grid, one file each: a 1.5px stroke (`stroke-icon`), round caps and joins, no fills, corners on rectangles eased by 1px (`rx="1"`). Precise and quiet, like the markings on an instrument panel: the plates, the cuts and the type carry the forge, the icons only name things.

In the app they render inline (`Icon`) with `stroke="currentColor"`, so they take the text colour: `muted` on an inactive nav item, `fg` when active, `gleam` on a live control. These files are inked in `#8f8377`, a mid iron between `line-strong` in Forge and in Ash, because an `<img>` cannot inherit colour; inline the path to colour it. The `general` icon's knobs are open in the files and masked with the ground colour inline.

Names and uses: `pipeline`, `inbox`, `backlog`, `agents`, `analytics`, `evals` label the six views; `general`, `pipeline`, `review`, `agents`, `tracker`, `dashboard`, `daemon`, `diagnostics`, `about` label the nine settings tabs; `close`, `command`, `search`, `play`, `stop`, `refresh`, `copy`, `settings` are controls; `board` and `table` label the layouts. Draw a new icon as one or two paths on the same grid at the same stroke, with the same even weight everywhere.
