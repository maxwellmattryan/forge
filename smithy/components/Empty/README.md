An empty state is a cold plate (`.plate.cold`: a dashed seam, no bevel, the smith's mark for "nothing on the anvil yet") with the Forge mark at 40px and one `body` sentence in `muted`, centred with `space-10` vertical padding. The sentence names the command that fills it, in `mono` `fg`.

Use it wherever a list has nothing yet: no jobs match, no backlog, no log lines, no evals. No button, no illustration beyond the mark.

Static rendition in the Smithy direction, hand-written from `design/components/Empty/preview.html` and `components/Empty.svelte`.
