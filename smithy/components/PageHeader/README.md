A page header is a riveted plaque (square-cornered, bolted at its four corners; `space-5` × `space-3.5` padding, `space-5` below) holding the `page-title` `h1` with a stamp line beneath it carrying what used to be the subtitle (`3 ACTIVE · BASE MAIN · GITHUB` in `stamp` mono between two short `line-strong` rules), and right-aligned controls that wrap under, inside the plate, on narrow screens. Text never sits on the grain, so the title, the stamp line and the controls all stay on the plate.

Use it once per view. The right slot holds the filter segments, the layout toggle and the one primary button, in that order. The command palette opens from the sidebar, not the page header (see Sidebar).
