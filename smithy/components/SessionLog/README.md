The session log is a control row (status chip, turns and cost in mono `muted`, Start/Stop, a search input, Tools/Thinking/Subagents checks, a Rendered/Raw `seg`, Follow and Load older) above a plate in `mono-log` with a sticky turn heading per turn, filled with `panel` so lines scroll under it. Items are chip-tagged lines, `details` blocks for tool calls (`→ name` in `gleam`, summary in `muted`, input and result as `pre` inside a `line-soft` box) and `info`-seamed blocks for subagents; errors are a `bad` chip and a `bad` seam.

Use it in the drawer's Log and, compact (288px), as the inbox's log in the status bar's Daemon popover. All text is untrusted output: assistant text, thinking and a subagent's prompt and report render as `prose compact` only through the escape-first `md()` (as text in Raw); tool input, results and every other line render as text.

Static rendition in the Smithy direction, hand-written from `design/components/SessionLog/preview.html` and `components/SessionLog.svelte`.
